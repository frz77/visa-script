# 🇵🇱 Visa Automation для Tampermonkey

## ⚙️ Установка

### 1️⃣ Установите Tampermonkey
- **Chrome:** https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobp9op
- **Firefox:** https://addons.mozilla.org/firefox/addon/tampermonkey/
- **Safari/Edge:** Поищите в своём app store

### 2️⃣ Установите скрипт
1. Откройте `visa_automation_tampermonkey.js` (скопируйте весь код)
2. В браузере нажмите иконку **Tampermonkey** → **Add new script**
3. Удалите стандартный код и вставьте наш скрипт
4. **Ctrl+S** для сохранения
5. Закройте редактор

✅ Готово! Скрипт теперь активирован.

---

## 🚀 Как использовать

### Способ 1️⃣ : Горячая клавиша
1. Загрузите JSON пресет (см. ниже)
2. Нажмите **Ctrl+Shift+V** на странице
3. Готово! ⚡

### Способ 2️⃣ : Кнопка UI
1. На странице откроется панель внизу справа (🇵🇱 Visa Bot)
2. Нажмите **"Загрузить пресет (JSON)"**
3. Выберите файл `preset_example.json` (или ваш пресет)
4. Нажмите кнопку **▶️ Запустить**
5. Смотрите логи в левой части панели

---

## 📋 Формат JSON пресета

Создайте файл `preset.json` (можно скопировать `preset_example.json`):

```json
{
  "rodzajUslugi": "Wiza krajowa - korzystanie z uprawnień wynikających z posiadania Karty Polaka",
  "lokalizacja": "Moskwa",
  "ludzie": "1 osob",
  "data": "2026-04-29"
}
```

### Поля:
- **`rodzajUslugi`** *(обязательно)* — название услуги из dropdown'а
- **`lokalizacja`** *(обязательно)* — город (Moskwa, Warszawa и т.д.)
- **`ludzie`** *(обязательно)* — количество (1 osob, 2 osoby и т.д.)
- **`data`** *(опционально)* — одна дата или список дат с приоритетом:
  - Одна дата: `"data": "2026-04-29"`
  - Несколько дат (приоритет по порядку): `"data": ["2026-04-29", "2026-04-30", "2026-05-01"]`
  - Если ничего не найдено или не указана → выбирается **первая доступная**

## 🔍 Как найти правильные значения для JSON?

Если скрипт не находит ваши значения:

1. Откройте консоль браузера: **F12**
2. На странице с формой откройте Developer Tools (F12)
3. Нажмите на dropdown в форме (первый селект)
4. Смотрите текст опций в HTML (Inspector)
5. Скопируйте точный текст в JSON

**Пример:** Если в dropdown'е написано:
```
Wiza krajowa - korzystanie z uprawnień wynikających z posiadania Karty Polaka
```

То в JSON нужно писать ровно это (или часть: `Karty Polaka`).

## 📝 Примеры пресетов

### Пример 1: Варшава, 1 человек, несколько дат (приоритет)
```json
{
  "rodzajUslugi": "Wiza krajowa - korzystanie z uprawnień wynikających z posiadania Karty Polaka",
  "lokalizacja": "Warszawa",
  "ludzie": "1 osob",
  "data": ["2026-05-15", "2026-05-16", "2026-05-17"]
}
```
Скрипт будет искать даты **в порядке приоритета**:
- Сначала 2026-05-15
- Если не найдена, то 2026-05-16
- Если не найдена, то 2026-05-17
- Если ничего не найдено, то первая доступная

### Пример 2: Москва, 1 человек, одна конкретная дата
```json
{
  "rodzajUslugi": "Wiza krajowa - korzystanie z uprawnień wynikających z posiadania Karty Polaka",
  "lokalizacja": "Moskwa",
  "ludzie": "1 osob",
  "data": "2026-05-15"
}
```

### Пример 3: 2 человека, первая доступная дата
```json
{
  "rodzajUslugi": "Wiza krajowa - korzystanie z uprawnień wynikających z posiadania Karty Polaka",
  "lokalizacja": "Moskwa",
  "ludzie": "2 osoby",
  "data": ""
}
```

3. Логи также выводятся в панели UI (внизу справа)
4. Проверьте, что значения в JSON точно совпадают с опциями в dropdown'е
